# Journal

Newest first. Written by `/journal` after each task, decision or debugging
session worth remembering.

Each entry: **what** changed, **why this shape** (the important one), **watch out
for**, and **refs**. Git already records what changed — this file exists for the
reasoning that git cannot hold.

Dead ends belong here too. An entry saying "tried X, it failed because Y" saves
more time than a successful one.
